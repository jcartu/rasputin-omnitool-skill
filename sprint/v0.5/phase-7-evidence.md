# Phase 7 evidence — Sub-agent tool (parallel fan-out)

## Summary
Added a first-class `sub_agent` tool that lets the executor spawn N parallel sub-agents to run independent sub-goals, then return aggregated results to the parent. Uses `ThreadPoolExecutor` for parallelism (model calls are I/O-bound, GIL is fine). Recursion blocked by default via tool denylist. Budget pre-flight check before spawning.
